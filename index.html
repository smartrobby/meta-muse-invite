가입 과정, 4단계로 보기

참고 글의 흐름을 바탕으로 새로 쓴 설명입니다. 화면 예시는 이해를 돕기 위해 제작한 그림이며 실제 서비스 화면과 다를 수 있습니다.

STEP 01접속 환경

접속 지역부터
확인하세요

참고 글은 스마트폰의 VPN 앱에서 미국 서버를 선택한 뒤 연결 여부를 점검하는 방법을 소개합니다. Muse의 지원 지역과 이용 약관을 먼저 읽고 접속 방법을 결정하세요.

  1. 스마트폰에서 신뢰할 수 있는 VPN 앱을 엽니다.
  2. 미국 서버를 선택했다면 연결 표시를 확인합니다.
  3. 가입을 진행하는 동안 연결이 유지되는지 살펴봅니다.
CHECK 지역 제한을 우회하면 가입이나 사용이 제한될 수 있습니다.
움직이는 안내예시 화면 · 3초 반복
STEP 02공식 페이지

Muse 가입 화면으로
이동하세요

브라우저에서 muse.ai/join을 열고, 그곳에 표시되는 가입 또는 로그인 절차를 진행하세요. 인증 메일이 오면 해당 메일함도 확인합니다.

  1. 주소가 muse.ai인지 확인합니다.
  2. 화면에서 제공하는 로그인 방식을 선택합니다.
  3. 필요한 인증을 완료합니다.
CHECK 비밀번호와 인증 코드는 이 안내 페이지에 입력하지 않습니다.
움직이는 안내예시 화면 · 3초 반복
STEP 03본인 확인

요청되는 확인 절차를
읽어보세요

가입 도중 연령이나 결제 수단 확인 화면이 나올 수 있습니다. 화면에 적힌 금액, 승인 방식, 취소·환불 조건을 확인한 뒤 본인에게 맞는 방법으로 진행하세요.

  1. 결제 또는 인증 안내의 세부 조건을 읽습니다.
  2. 본인 명의 정보만 사용합니다.
  3. 처리 결과와 결제 내역을 확인합니다.
CHECK 참고 글의 ‘$1 즉시 환불’ 설명은 공식 확인이 되지 않아 보장하지 않습니다.
움직이는 안내예시 화면 · 3초 반복
STEP 04초대 코드

초대 코드 메뉴를
찾아 입력하세요

가입을 마쳤다면 Muse 화면의 메뉴나 설정에서 초대 코드 등록 항목을 찾아보세요. 영문 화면에서는 ‘Redeem Invite Code’처럼 표시될 수 있습니다. 메뉴 이름과 위치는 변경될 수 있습니다.

  1. 메뉴 또는 설정을 엽니다.
  2. 초대 코드 등록 항목이 있다면 이 페이지의 코드를 입력합니다.
  3. 적용 결과와 계정 혜택을 직접 확인합니다.
CHECK 코드 입력 가능 기간과 토큰 지급량은 Muse의 실제 안내를 따르세요.

GOOD TO KNOW

자주 확인하는 내용

한국에서도 Muse에 가입할 수 있나요?+

Meta의 2026년 9월 공식 발표에서는 미국 출시를 안내합니다. 한국 이용 가능 여부와 대기 등록 여부는 공식 가입 화면에서 확인해 주세요.

초대 코드를 넣으면 토큰을 반드시 받나요?+

보상 수량과 지급 조건은 공식 Muse 화면에 표시되는 내용이 기준입니다. 이 페이지는 특정 수량의 토큰 지급을 보장하지 않습니다.

카드 확인 중 청구가 보이면 어떻게 하나요?+

결제 화면의 조건과 카드사 거래 내역을 확인하세요. 청구나 환불 문제는 Muse 공식 지원 채널과 카드사에 문의하는 것이 정확합니다.
